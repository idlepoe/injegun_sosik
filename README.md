## 인제군청 소식

- **대시보드**: 날씨, 공지사항, 이번 주 행사, 합강소식지 요약·슬라이더
- **푸시 알림**: 주간일정·공지·구인구직·생활장터·자유게시판 토픽별 구독/해제
- **목록·상세**: 공지·구인구직·생활장터·자유게시판·주간일정 목록 및 글 상세·원본 링크
- **합강소식지**: PDF 뷰어로 소식지 열기
- **설정**: 알림 온/오프, 토픽별 알림 on/off

본 앱은 인제군청에서 공식적으로 제공하는 앱이 아니며, 인제군청 공식 홈페이지(https://www.inje.go.kr/portal) 에 공개된 게시물을 모바일 환경에서 보기 쉽도록 정리하여 제공하는 비공식 정보 제공 앱입니다.

앱에 표시되는 모든 게시물은 인제군청(공공기관)이 관리·검토·게시한 공개 자료이며, 사용자는 앱 내에서 게시물을 작성, 수정, 댓글 작성, 업로드하거나 다른 사용자와 상호작용할 수 없습니다.

일부 게시물은 일반 사용자가 인제군청의 공식 민원·제안 창구를 통해 제출한 내용일 수 있으나,
해당 게시물의 게시 여부 및 관리는 전적으로 인제군청의 책임 하에 이루어집니다.
